# Adding official photos

The site uses a photo automatically when a file with the right name exists. Anything missing keeps its illustration, so you can add photos a few at a time.

## Where to get them
Rockstar's GTA VI site → Downloads (Media & Artwork) → Screenshots → "Download All" (one zip, about 99 images).
The Artwork & Wallpapers set has character portraits too. Every file is named after the character or place it shows.

## Before uploading
Resize each image to about 1600 px wide and save as JPG (quality around 80). Files should be roughly 200–400 KB.
Free ways: squoosh.app in the browser, or Windows PowerToys Image Resizer.

## Where to put them and what to name them
The first image is the main photo (cards and page header). Add -2, -3 … for a gallery on that page.
Character photos: portrait or close-up shots work best (cards are tall).

## Rules
- Only official Rockstar images. Never leaked or AI-made ones.
- Every photo shows "Image: Rockstar Games" automatically. Keep it.
- If Rockstar or Take-Two ever asks you to remove an image, delete the file and commit.
